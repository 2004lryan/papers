# Datasets — sources, licenses, and availability

This repository ships the data card (see `../docs/`), the derived result files and the
deterministic extractions of two published tables; it does not re-host the avocado dataset,
which is obtained from its official source below. The SHA-256 values in the tables below are
the first 16 hex digits; the full digests are in `SHA256-MANIFEST.tsv` in this directory and in
`../outputs/120datacard_sha256.json`, regenerated by `python code/120datacard_sha256.py` and
`python tools/make_manifest.py`.

No new data were collected for this work. All three real systems are
previously published, openly licensed third-party data.

## External public datasets (download from the official source; not re-hosted)

| Dataset | Role in the paper | Source | License | SHA-256 (16) |
|---|---|---|---|---|
| Hass avocado postharvest ripening (photographic) | Real system 3 — the only system with a genuine sampling distribution (478 fruit, 14,722 records) | [Mendeley Data, doi:10.17632/3xd9n945v8.1](https://doi.org/10.17632/3xd9n945v8.1) | CC BY 4.0 | `f8abeaba6eedf678` |
| Apple firmness temperature gradient (Table A1, the 17th table element of the article, whence the shipped file name `PMC10253207_T16.csv`) | Real system 1 — 4 cultivars × 5 storage temperatures × 5 time points; design-window sweep | [Foods 2023, doi:10.3390/foods12112113](https://doi.org/10.3390/foods12112113) | CC BY 4.0 | `d22131f037a120e7` |
| Long-shelf-life food kinetics, ammonia / TBARS (Table 3) | Real system 2 — 5 foods × 4 storage temperatures, 10 sequences; independent replication | [Foods 2022, doi:10.3390/foods11142004](https://doi.org/10.3390/foods11142004) | CC BY 4.0 | `ee6da3d22db941fe` |

The last two are **published tables inside open-access articles**. This repository
ships the deterministic extraction (`pandas.read_html`) of those tables,
`processed/pmc_real/PMC10253207_T16.csv` and `processed/pmc_real/PMC9319022_T3.csv`, checked
value by value against the Europe PMC full text and by hand. The avocado xlsx is
read directly with no numerical transformation and is **not** re-hosted here.

## Derived artefacts (shipped in this repository)

Every number in the manuscript traces to a shipped artefact. The principal ones are listed
here; the complete set is `SHA256-MANIFEST.tsv` in this directory, 98 files plus the one
external dataset above. What the tooling checks is that each of those rows is present and
hashes as recorded; that the set itself is complete is enforced upstream, by the data card's
reverse gate — see the note in the top-level README.

| File | Content | SHA-256 (16) |
|---|---|---|
| `43trichotomy_formal.json` | Semi-synthetic trichotomy: terminal Ψ, collapse slopes, Krug-line match | `771986e2487d00f3` |
| `54c5_realkinetics.json` | Apple system: per-cultivar Eₐ and R², design sweep, over-determined subsets | `b758bd9a95da3758` |
| `54c5_realkinetics-designsweep.csv` | The 26 apple temperature subsets, one row each (source of Table S2) | `7a598b3e1aa8494f` |
| `91c5_realkinetics_killer.json` | Ψ versus inexpensive heuristics; Ψ_het across systems | `79f6df8ca0e94179` |
| `99_realkinetics2.json` | Food system: Eₐ range, homogeneous / heterogeneous Ψ replication | `b41c66625cde8d18` |
| `102_avocado_c5_pilot.json` | Avocado system: genuine statistical estimation error, sweep along n | `125ba608e1256276` |
| `119pazman_pronzato_bridge.json` | Coordinate check against the Pázman–Pronzato (2006) worked example | `6d5f827620897f26` |

Semi-synthetic data are not shipped as files — they are regenerated
deterministically from fixed seeds by the scripts.

Each dataset is used under its own license; please cite the original sources.
The data card `../docs/0NDATACARD_C5.md` gives the same pointers, with the full digest of each
source dataset; `python tools/make_manifest.py --check` re-verifies every digest in
`SHA256-MANIFEST.tsv` against the shipped bytes.
