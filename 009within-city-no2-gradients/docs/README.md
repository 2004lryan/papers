# Data cards

One card per table that the analysis reads: path, building script, source, licence, size, SHA-256 and the meaning of
each column the scripts use. The tables themselves are not in this repository; `../data/DATA.md` explains how to obtain
them.

| Card | Table |
|---|---|
| `station-annual-panel-datasheet.md` | Station annual panel, 2015-2024 |
| `station-register-datasheet.md` | Station register with coordinates |
| `builtup-exposure-datasheet.md` | Built-up exposure at 500 m and 1000 m |
| `provincial-nev-stock-datasheet.md` | Provincial new energy vehicle stock, 2017-2023 |
| `city-vehicle-stock-datasheet.md` | City panel with vehicle stock, 2017-2023 |
| `city-covariates-datasheet.md` | City covariates, 2017-2023 |
| `provincial-covariates-datasheet.md` | Provincial covariates, 2017-2023 |
| `city-meteorology-datasheet.md` | City meteorology, 2015-2024 |
