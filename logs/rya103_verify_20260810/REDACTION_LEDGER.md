## 替换规则（符号化；**本台账刻意不复现被替换的字面私有串**）

把私有串写进随发布件一起走的台账，等于把刚脱掉的东西又贴回去。下表只给规则的符号化
描述；每个文件脱敏**前**的 SHA-256 已足以锁死原文，任何持有正典留痕的人都能逐字节复核。

| # | 规则（符号化） | 为什么与证据内容无关 |
|---|---|---|
| R1 | `PROJ="<项目根绝对路径>"` → `PROJ="${ARIS_PROJECT_ROOT:?…}"` | runner 的项目根赋值 → 环境变量占位；保留脚本可运行性，不写死作者机路径 |
| R2 | `<项目根绝对路径>/` → `(空，即仓库相对路径)` | 项目根绝对路径 → 仓库相对路径；相对路径即证据内容本身，逐字保留 |
| R3 | `<家目录>/.cache/rya103_verify/` → `${SANDBOX}/` | RYA-103 复跑沙箱根 → 占位符；沙箱位置是一次性机器事实，被审文件的相对路径逐字保留 |
| R4 | `workdir: <家目录>` → `workdir: ${HOME}` | 会话元数据里的 workdir → 占位符；该值只记录调用时的当前目录，不承载证据 |
